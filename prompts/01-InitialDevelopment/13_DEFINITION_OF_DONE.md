# Definition of Done (Per Milestone)

For each milestone:
- dotnet test passes
- docker compose up works (api + ui)
- UI can call API health endpoint
- milestone features complete
- state files updated
- Milestone Commit Notes produced

Final DoD (M6):
- All endpoints implemented and functional
- Repo config persistence stable
- Roslyn + Buildalyzer analysis functional
- Git CLI analysis functional (tree/history/co-change)
- UI dashboard + IDE-like explorer functional
- docs + scripts complete
